# 概念と境界

- **本体と利用者のリポ**: 本体（このリポ）は生成器だけを持つ。設定・拡張・生成物・配信ブランチは、利用者が別に持つリポ（配信するリポ）に置く。本体に利用者固有の値や生成物を入れない
- **ルート（`[[roots]]`）とグループ**: どのリポを読むかの単位。`path` は1つのリポ、`children` は直下の git リポすべて。グループ名はページの見出しとアカウントへの割り当てに使う
- **アカウント（`[[accounts]]`）**: Issue の取り込みと表示を分ける単位。1〜2個。リポは remote のホストかグループでアカウントに属する。アカウントをまたぐ Issue の参照は作らない。GitHub の取り込みはアカウントごとに `gh_config_dir` を分けられる
- **Issue の取り込み元**: 標準は GitHub（open な Issue）。それ以外は拡張の `issues()` が返す。GitHub の本文は他人の文章として扱い、拡張の取り込み元だけが `trusted` を立てられる
- **拡張**: 本体の外に置く Python モジュール。本体は決まった口を呼ぶだけで、拡張の中身を知らない
- **生成物と配信**: `public/` と `functions/` は全リポのコードを含む。公開してよい場所ではなく、Cloudflare Access の後ろでだけ配る。`*.pages.dev` は `_middleware.js` で塞ぐ
